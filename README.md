# 📱 Android Scrollable List App

Aplikasi sederhana yang menampilkan daftar item berurutan (*scrollable list*)[cite: 2]. Proyek ini dirancang untuk mendemonstrasikan implementasi komponen list (seperti `RecyclerView` atau `LazyColumn` pada Jetpack Compose) di Android.

## ✨ Fitur Utama

- **Scrollable List View:** Menampilkan daftar dinamis dari `Item 1` hingga `Item 20`[cite: 2].
- **Efisien & Responsif:** Menggunakan alokasi memori yang efisien untuk rendering elemen list secara *real-time*.
- **Dukungan Dark Mode:** Tampilan antarmuka yang menyesuaikan dengan tema gelap (Dark Theme)[cite: 2].

---

## 🛠️ Teknologi yang Digunakan

- **Language:** Kotlin / Java
- **UI Toolkit:** Jetpack Compose (`LazyColumn`) / XML Layouts (`RecyclerView`)
- **IDE:** Android Studio
